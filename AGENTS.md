# Wordgarden agent guide

- Keep project documentation in English; retain Vietnamese UI labels in user instructions.
- For a new feature or material behavior change, read [feature rules](docs/features/README.md) and create its record before coding. Small fixes and routine maintenance do not need a feature record.
- For code changes, follow [development and testing](docs/development.md). For a release or deployment, follow [release rules](docs/releases/README.md).
- For Git setup, commits, or GitHub publication, follow the [personal GitHub workflow](docs/git-workflow.md), including sensitive-content review and secret scans before pushing.
- Update the relevant record and documentation with the work. Report checks that failed or were not run; never list unfinished work as released.
